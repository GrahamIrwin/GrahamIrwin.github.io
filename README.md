# GrahamIrwin.github.io

My personal site: a resume and a few projects, with a retro terminal look.

It's plain HTML and CSS with no build step. Edit `index.html` and `style.css`, then push to `main`, and GitHub Pages
serves it. To preview it locally, open `index.html` in a browser. Printing the page gives a plain black-on-white resume.

The earlier version was built with Pelican for a technical writing course. It's still in the git history (`38bf37e`
and earlier).
