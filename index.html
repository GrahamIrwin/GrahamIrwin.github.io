01 FlyAim

2026 → now · TRAINING

Janelia's full MaleCNS v1.0 fruit fly connectome (164,866 neurons, 25.5M synapses) simulated on the GPU as a leaky integrate-and-fire spiking reservoir that plays Counter-Strike 2. The synapses stay fixed. Only a linear ridge-regression readout to the game's actions is learned.

  • Rewrote the simulation step as a sparse (CSR) matrix-vector product, so the full brain runs in real time at the game's tick rate, and batched it to run many brains at once.
  • Tuned the network out of its chaotic regime and widened the readout to interneurons, which made it much better at imitating a scripted teacher.
  • Learns online from live play (DAgger plus reward-weighted regression), and only deploys a new readout if it beats the current one on unseen data. It trains through self-play across parallel headless game servers.
  • Python
  • PyTorch
  • CUDA
  • C#

02 Discrete Math, Interactive

2026 · OPEN TEXTBOOK

An open textbook for MATH 1240 Discrete Mathematics, written in PreTeXt as a research assistant on an OER grant. The best part is the interactives, which I built in plain JavaScript so students can try the ideas instead of just reading about them:

  • Graph isomorphism: drag the vertices of a random graph onto the Petersen graph and watch the mapping table fill in.
  • Function builder: drag arrows between two sets to build a function, and see right away whether it's injective, surjective or bijective.
  • Euclidean algorithm: step through the division steps to gcd(a, b), then the back-substitution that finds x and y with ax + by = gcd(a, b).
  • Linear congruence solver: turns ax ≡ c (mod n) into a Diophantine equation and walks through every incongruent solution.
  • Also: truth tables, Venn diagrams, number base conversion and password counting.
  • JavaScript
  • PreTeXt
  • Discrete math
  • OER

03 Paper2LaTeX

2026 · V1, EARLY

Turns photos or PDFs of handwritten math and CS notes into structured LaTeX, entirely offline on a local vision model (Qwen2.5-VL 7B through Ollama). There are no API calls and no per-page cost, and your notes never leave the machine. The goal is structure, not just text: aligned derivations become align* and boxed results become theorem environments.

  • Flags problems instead of guessing. Unreadable passages get %% UNSURE comments that are collected into a "Review these" page, and hand-drawn diagrams are cropped from the photo and embedded.
  • Checks each photo for blur, low contrast and bad exposure before it reaches the model.
  • Handwriting profiles: photograph one sentence of your writing and the model writes a glossary of your quirks to use on every page.
  • A desktop app styled after Windows 95. Attach the question sheet and each question is boxed above its answer, or ask for edits in plain English. A rewrite is refused if it drops content or gets stuck in a loop.
  • Python
  • Ollama
  • Vision LLMs
  • LaTeX
  • Tkinter

04 MTG Vec2Search

LIVE

Search every Magic: The Gathering card by describing it in plain English ("cheap green elves that ramp"), or paste a Commander deck to see what similar decks play that yours doesn't. It's a static site. A build step turns Scryfall's bulk data and about 3,000 community oracle tags into a sharded index, so the first search downloads about 200 KB and later ones a few KB. Results are ranked by IDF-weighted query coverage, and prices are shown in the visitor's local currency.

  • JavaScript
  • Python

05 LogicParser

STABLE

A Python toolkit for sentential logic. It checks whether a formula is well formed and finds its main connective, and it identifies which inference rule gets from a set of premises to a conclusion. It also comes with generators that produce valid and invalid formulas for testing, or for practice problems.
